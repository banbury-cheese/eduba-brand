# Eduba Voice Reference

## Two contexts, two files

- **Product/in-app copy** (buttons, labels, errors, empty states, toasts): use this file.
- **Marketing/editorial copy** (articles, social, founder voice): this file covers the short version; the full system is in `voice/VOICE.md`.

---

## Product voice

Tone: calm, exact, useful. Sounds like a strong operator, not a founder.

**Buttons — direct verbs only:**
```
Do:   "Open Case" / "View Project" / "Start A Conversation" / "Ask For Access"
Don't: "Unlock The Future" / "Transform Your Workflow" / "Explore Possibilities"
```

**Empty states — three parts:**
1. What this area is
2. Why nothing is here yet
3. What to do next

Example: `No case studies have been added yet. Add the first entry to start building the archive.`

**Errors — plain and specific:**
```
Do:   "This file could not be uploaded. Try a smaller image or a different format."
Don't: "Something went wrong."
```

**Success — brief:**
`Saved` / `Invite sent` / `Review updated` / `Message opened ✓`

**Toasts:** Short, uppercase, mono. `LINK COPIED` / `VOX-MEET IS COMING SOON.` / `PROJECT OPENED`

**Section headings — declarative, spare:**
```
Do:   "Build What Makes Sense" / "Case Studies" / "Govern What Works"
Don't: "Solutions For Modern Teams" / "The Future Of Intelligent Transformation"
```

**Forbidden words:** unlock, revolutionary, game-changing, magic, seamless, empower, leverage, reimagine, future-proof.

## Marketing voice (brief)

Register: Calm, measured, architectural. A teacher leaning forward.

Rules:
1. Calm confidence, never hype.
2. Lead with insight, not credentials.
3. Concrete over abstract — use exact numbers.
4. Understate. Facts carry weight.
5. One concept per piece.
6. **Never use em dashes.** Commas, periods, or restructure.
7. Land with a sentence that reframes.

Proof points available:
- 600+ people trained (Pacific Life, Colgate-Palmolive, KPMG UK, IAG)
- 95% sustained adoption vs ~10% industry average
- 6,000–9,000 hours saved annually per client

Positioning: "When not to use AI" — the counter-position that earns trust.
